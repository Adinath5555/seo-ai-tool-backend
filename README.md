# SEO AI Tool

SEO auditing tool built with FastAPI, React, SQLite and Gemini AI.

## Features

- Website SEO Audit
- Title Analysis
- Meta Description Analysis
- H1 Tag Count
- Image Alt Tag Check
- SEO Score Calculation
- AI-Powered SEO Recommendations using Gemini

## Backend Setup

```bash
cd seo-ai-tool
myvenv\Scripts\activate
uvicorn main:app --reload
```

## Frontend Setup

```bash
cd seo-ui
npm run dev
```

## Tech Stack

- FastAPI
- React
- SQLite
- BeautifulSoup
- Gemini AI
